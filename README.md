
# MP3 Tag Reader

## Description
MP3 Tag Reader is a C project that reads and displays ID3v1 metadata from an MP3 file.

## Features
- Extracts the song title.
- Displays the artist name.
- Displays the album name.
- Reads the release year.
- Displays the comment and genre ID.

## Technologies Used
- C Programming
- File Handling
- Structures
- Command-Line Arguments
- Makefile

## Compilation
Compile the project using:

    make

## Execution
Run the program by providing an MP3 filename:

    ./mp3_tag_reader Sanam.mp3

## Sample Output
    Title   : My Song
    Artist  : Arijit Singh
    Album   : Animal
    Year    : 2025
    Comment : Nice song
    Genre   : 13
